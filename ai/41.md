3.3 把 gap 转成 “自编程任务”
在 SelfImprovementManager 里增加一个入口：

async def run_blueprint_alignment_cycle(self):
    gaps = await self.blueprint_tracker.scan()

    for cap_name, info in gaps.items():
        if info["status"] == "implemented":
            continue

        # 根据缺失的 requirement 生成任务描述
        task_desc = self._describe_task(cap_name, info["missing_requirements"])
        # 调用自编程引擎生成 patch 草稿
        patch_id = await self.self_programming.propose_patch_for_capability(
            capability_name=cap_name,
            task_description=task_desc,
        )
        # 为 patch 创建 experiment
        await self._create_experiment_for_patch(patch_id)
这里 propose_patch_for_capability 会调用 LLM：

读 yaml 里的 spec + 当前代码；

在 /mutable/ 区域生成 patch（diff 形式）；

自动生成基础测试（比如同名 test_*.py）。
