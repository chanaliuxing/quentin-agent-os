blueprint:
  id: "meta_agent_v3"
  codename: "Project Quentin"
  version: "3.0"
  edition: "Research-Integrated"
  description: >
    Meta-Agent v3: a research-integrated, self-evolving AI operating system
    with continual memory, self-programming, and experiment-friendly design.
    元目标：在安全边界和可回滚前提下，让智能体在多领域中持续学习 / 自演化 / 自改代码。

  goals:
    - id: g.continual_memory
      text: >
        Provide a continual, multi-tier memory system (STS/MTS/LTS) that can run long-term
        without stuffing all history into a single LLM context.
    - id: g.self_programming
      text: >
        Provide a self-programming engine that can generate code candidates, run tests,
        evaluate benefits/risks, and manage code patches under safety constraints.
    - id: g.research_friendly
      text: >
        Provide clear experiment interfaces for all main loops (cognitive / immune /
        sleep / skill&code evolution) with well-defined inputs/outputs/metrics, so new
        algorithms can be plugged in and compared.

  non_goals:
    - id: ng.full_autonomy_without_oversight
      text: "Do NOT pursue a fully unsupervised system without any governance or kill switch."
    - id: ng.modify_kernel_schema
      text: "AI must NOT modify the safety kernel or core schema definitions at runtime."
    - id: ng.solve_all_research
      text: "Do NOT aim to solve multi-agent game theory or full architecture search in v3."

  design_principles:
    - "trace_everything: 无 Trace 不执行"
    - "kernel_vs_mutable: 安全内核与可自改模块严格分区"
    - "sandbox_first: 所有自演化实验从 sandbox 起步"
    - "governance_first: 所有自改决策经过 AI 治理层（多智能体 + 宪法）"

直接存成文件：

BlueprintGapTracker 做的事就很清晰了：

按 capabilities.*.components 用 importlib 检查模块/类是否存在；

对比 requirements 构造 “implemented / placeholder / missing”；

给每个 capability 打一个 status 和 missing_requirements 列表。

后面你要做“蓝皮书自我迭代”的所有逻辑（任务生成、自编程、AI 审批），都可以直接挂在：

blueprint.capabilities（定义了要补齐什么）

phases（定义了推进顺序）

challenges（给 Research Layer 用来挑选优先研究方向）

如果你愿意，下一步我就直接帮你落地 BlueprintGapTracker.scan() 的 Python 骨架，用这份 YAML 做真实解析和 gap 输出。
