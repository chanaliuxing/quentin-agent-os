1. 替换 _run_planner 实现
用下面这个版本覆盖你现在的 _run_planner（注意把 PlannerResult 字段名对齐你自己的 dataclass）：

    def _run_planner(self, goal: "Goal", context: Dict[str, Any]) -> "PlannerResult":
        """
        Planner v2：使用 planner council 做多模型规划。

        - 先从 SkillManager 获取相关技能建议；
        - 构造 CouncilQuestion(topic='planner')；
        - 交给 self.council_manager.run_council('planner', question)；
        - 从决议中的 final.answer 取出标准化计划 JSON；
        - 转成 PlannerResult 返回。
        """
        domain = getattr(goal, "domain", None) or "core"
        task_text = goal.description or goal.title or getattr(goal, "raw_text", "") or ""
        if not task_text:
            task_text = f"Goal {getattr(goal, 'id', None)}"

        # 1) Skill suggestions
        skill_suggestions: List[Dict[str, Any]] = []
        try:
            if self.skill_manager is not None:
                skill_suggestions = self.skill_manager.suggest_for_task(
                    task_text=task_text,
                    domain=domain,
                    top_k=5,
                    include_candidates=True,
                )
        except Exception:
            logger.exception("CognitiveLoop._run_planner: failed to get skill suggestions")

        # 2) 构造 planner council 的问题
        goal_payload = {
            "id": getattr(goal, "id", None),
            "title": getattr(goal, "title", None),
            "description": goal.description,
            "domain": domain,
            "metadata": getattr(goal, "metadata", {}),
        }
        question_payload = {
            "goal": goal_payload,
            "context": context or {},
            "known_skills": skill_suggestions,
            # 给各个成员/仲裁器的 schema 提示
            "plan_schema_hint": {
                "steps": [
                    {
                        "step_id": "s1",
                        "description": "Natural language description of this step.",
                        "skill_id": "<optional skill_id from known_skills or null>",
                        "notes": "optional clarifications for Executor / tools",
                    }
                ]
            },
        }

        importance = (goal_payload.get("metadata") or {}).get("importance", "normal")

        question = CouncilQuestion(
            topic="planner",
            importance=importance,
            prompt=(
                "Decompose the given GOAL into a small sequence of executable steps.\n"
                "Use KNOWN SKILLS when clearly helpful, by referencing their skill_id.\n"
                "You MUST return a JSON object under the 'answer' field with structure:\n"
                "{\n"
                "  \"steps\": [\n"
                "    {\"step_id\": \"s1\", \"description\": \"...\", \"skill_id\": \"...\" | null, \"notes\": \"...\"},\n"
                "    ...\n"
                "  ]\n"
                "}\n"
            ),
            payload=question_payload,
        )

        # 3) 调用 planner council
        decision = self.council_manager.run_council("planner", question)

        # 4) 从 final.answer 中拿到 plan_obj
        plan_answer = decision.final.get("answer")
        if isinstance(plan_answer, str):
            # 有些模型会把 JSON 当字符串返回，这里尝试再 parse 一次
            try:
                plan_obj = json.loads(plan_answer)
            except Exception:
                logger.exception("CognitiveLoop._run_planner: failed to parse plan answer string; using fallback.")
                plan_obj = {}
        elif isinstance(plan_answer, dict):
            plan_obj = plan_answer
        else:
            plan_obj = {}

        # 5) 容错：如果 plan_obj 没有 steps，就退化为一个单步
        steps_list = []
        raw_steps = plan_obj.get("steps") if isinstance(plan_obj, dict) else None
        if isinstance(raw_steps, list) and raw_steps:
            for s in raw_steps:
                steps_list.append(
                    {
                        "step_id": s.get("step_id") or f"s{len(steps_list)+1}",
                        "description": s.get("description") or "",
                        "skill_id": s.get("skill_id"),
                        "notes": s.get("notes"),
                    }
                )
        else:
            # fallback：把仲裁的 reasoning 当作一个大步骤
            steps_list.append(
                {
                    "step_id": "s1",
                    "description": decision.final.get("reasoning")
                    or f"Execute goal in one step: {task_text}",
                    "skill_id": None,
                    "notes": "planner_fallback_single_step",
                }
            )

        # 6) 组装 PlannerResult（字段名称按你实际的 dataclass 调整）
        result = PlannerResult(
            goal_id=getattr(goal, "id", None),
            raw_output=json.dumps(decision.to_dict(), ensure_ascii=False),
            steps=steps_list,
            used_skills=skill_suggestions,
        )
        return result
🔧 注意：

PlannerResult 的构造参数要对齐你自己的定义；如果没有 used_skills 字段，可以去掉这一项。

decision.to_dict() 里包含了所有成员的意见，后续 SleepLoop / Research Layer 可以拿这个做研究分析。

五、现在 Planner 这条链路的状态
到这一步，做计划的链路变成：

CognitiveLoop._run_planner：

从 SkillManager 查可用技能；

构造 CouncilQuestion(topic="planner", payload=[goal/context/skills])；

送进 planner council。

CouncilManager：

读取 config/councils.yaml 的 planner 部分；

让多个成员（比如 deepseek-r1, qwen2.5）各自按 计划 schema 给出 answer.steps[]；

由仲裁 LLM 统一选择 / 融合出一个最终的 plan JSON。

_run_planner：

从 decision.final.answer 取出 plan；

把 steps 转成 PlannerResult.steps，交给 Executor。

Executor：

看每个 step 的 skill_id；

能用技能就直接调用 auto_skills 里的 Python 函数；

否则 fallback 到 LLM 执行；

执行记录写成 StepExecutionRecord，再被 CognitiveLoop 汇总成 execution_summary。

下一次 SleepLoop + 自编程引擎可以：

从成功 Trace 中挖出好用的规划模式 / 技能，

生成新 skill / 新工具，

SkillImplementationEngine 自动实现，

下次 planner council 的各个成员在回答 plan 时就能看到更多技能，

再通过仲裁器生成更结构化、更可执行的计划。

如果你继续说「继续下一步」，我会优先往 “错误反省 / 多次失败后触发 reflection council” 方向落地：

实现 ReflectionCouncil（封装 CouncilManager 的 reflection topic）；

当某个任务重复失败或指标异常时，自动触发多 AI 诊断：

分析为什么会失败；

提出新的 plan 或新的 skill 需求；

这些信息再喂回 SleepLoop 和自编程引擎，形成一个真正的“自我纠错 / 自我进化”闭环。
