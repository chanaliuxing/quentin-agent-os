3. 四大循环（Loops）
3.1 认知循环（Cognitive Loop）
✅ 有基础骨架：

CognitiveLoop（你之前就有，能按任务调用 planner → executor → critic → 记录 trace）。

🧱 占位或弱实现：

Planner 现在是 “Echo Plan”：

固定生成一个 llm_call 类型的单步 plan，没有真正的分解 / 任务树 / 分层规划。

Executor 只支持 kind == "tool" 的简单调用，对 skill / llm_call 只是 noop 占位。

Critic 是固定两句模板：“成功/失败”，没有 LLM 反思（Reflexion）和结构化错误原因。

❌ 缺失：

任务级别的成功度量（success_score / reward）并没有完整 schema 和记录。

✅ 有 ImmuneLoop / ImmuneCase schema / list_cases / 统计接口。

🧱 占位：

自动降级策略（关掉自改代码 / 切换到 safe planner / 降低探索度）
