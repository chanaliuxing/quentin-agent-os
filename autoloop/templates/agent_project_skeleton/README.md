# Agent Project Skeleton

This skeleton provides a minimal stable base:

- `runtime/event_log`
- `runtime/evidence`
- `runtime/metrics`
- `policies/failure_router_policy.json`
- `policies/recovery_rollout_policy.json`
- `scripts/ci_control_plane_gate.sh`
- `schemas/contracts/evidence_record.schema.json`

Use `scripts/bootstrap_agent_project.py` to instantiate a new project from this template.
