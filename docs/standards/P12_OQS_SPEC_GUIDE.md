# P12 Open Quentin Spec (OQS) Guide

## Versioning
OQS follows SemVer. Current version is `1.0.0`.

## Core Schemas
- **Tools**: Standardizes input/output formats for cross-node tool calls.
- **Audit**: Defines universal audit log entries for organizational accountability.
- **Attestation**: Standardizes the layout of trust proofs.

## Validation
Use the `OQSValidator` to ensure your extensions are compliant before publication.
