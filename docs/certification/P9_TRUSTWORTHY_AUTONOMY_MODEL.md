# P9 Trustworthy Autonomy Model

## Maturity Levels
- **L0 (Manual)**: All changes require human PR.
- **L1 (Assisted)**: System suggests, human applies.
- **L2 (Partial)**: Auto-apply in sandbox, human promotes.
- **L3 (High)**: Auto-promotion with strict evaluation gates.
- **L4 (Full)**: Autonomous strategic roadmap execution.

## Dimension Scoring
- **Safety**: Suppression rate vs False Positives.
- **Reliability**: Success rate and MTTR.
- **Governance**: Policy coverage and audit compliance.
