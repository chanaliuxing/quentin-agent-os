# Memory Adaptive Degrade Tuning Guide

## Scope
This guide tunes cross-session recall stability under timeout pressure.

## Core Env Knobs
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_DEGRADE_ENABLE`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_PRESSURE_THRESHOLD`
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_SESSION_CAP_FACTOR`
- `QUENTIN_MEMORY_SEARCH_CONCURRENCY`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_S`
- `QUENTIN_MEMORY_SEARCH_OVERALL_TIMEOUT_S`
- `QUENTIN_MEMORY_SEARCH_MAX_SESSIONS_SCANNED`
- `QUENTIN_MEMORY_SEARCH_MAX_CANDIDATES_RERANKED`

## Presets
### Small Workload (<= 10 sessions)
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_DEGRADE_ENABLE=1`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_PRESSURE_THRESHOLD=0.6`
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_SESSION_CAP_FACTOR=4`
- `QUENTIN_MEMORY_SEARCH_CONCURRENCY=4`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_S=3`
- `QUENTIN_MEMORY_SEARCH_OVERALL_TIMEOUT_S=8`
- `QUENTIN_MEMORY_SEARCH_MAX_SESSIONS_SCANNED=0`
- `QUENTIN_MEMORY_SEARCH_MAX_CANDIDATES_RERANKED=0`

### Medium Workload (10-50 sessions)
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_DEGRADE_ENABLE=1`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_PRESSURE_THRESHOLD=0.4`
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_SESSION_CAP_FACTOR=3`
- `QUENTIN_MEMORY_SEARCH_CONCURRENCY=6`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_S=2.5`
- `QUENTIN_MEMORY_SEARCH_OVERALL_TIMEOUT_S=10`
- `QUENTIN_MEMORY_SEARCH_MAX_SESSIONS_SCANNED=36`
- `QUENTIN_MEMORY_SEARCH_MAX_CANDIDATES_RERANKED=120`

### Large Workload (>= 50 sessions)
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_DEGRADE_ENABLE=1`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_PRESSURE_THRESHOLD=0.25`
- `QUENTIN_MEMORY_SEARCH_ADAPTIVE_SESSION_CAP_FACTOR=2`
- `QUENTIN_MEMORY_SEARCH_CONCURRENCY=8`
- `QUENTIN_MEMORY_SEARCH_TIMEOUT_S=2`
- `QUENTIN_MEMORY_SEARCH_OVERALL_TIMEOUT_S=12`
- `QUENTIN_MEMORY_SEARCH_MAX_SESSIONS_SCANNED=64`
- `QUENTIN_MEMORY_SEARCH_MAX_CANDIDATES_RERANKED=80`

## Validation Checklist
- Check `memory.events.recall.cross_session_timeouts` trend in observability.
- Check `memory.events.recall.rerank_applied` does not drop to 0 for normal load.
- Check `memory.embedding_batch_hints` has no sustained retry/fallback spike hints.
